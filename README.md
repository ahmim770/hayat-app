# Hayat (حياة) — Unified Hospital App

Live on the App Store: https://apps.apple.com/sa/app/hayat-%D8%AD%D9%8A%D8%A7%D8%A9/id6761381908

Hayat connects hospitals across Riyadh into one mobile platform. Patients can search hospitals, view
available doctors, and book appointments without juggling separate hospital systems — plus an AI
assistant that takes symptoms in Arabic or English and recommends the right specialty and doctor.
The app also brings together pharmacy access, lab results, prescriptions, and vaccination records,
with built-in emergency support for fast access when it matters most.

Built as a senior project (IS499) at Prince Sultan University, supervised by Dr. Omaia Al-Omari.
